# Portfolio & CV Web — Javier Sáez

Sitio web oficial, portfolio y currículum interactivo bilingüe (Español / English) de **Javier Sáez** — Trombonista, Tubista/Bombardinista, Pedagogo Musical e Investigador.

Desarrollado con [Astro](https://astro.build/) y [Tailwind CSS](https://tailwindcss.com/), diseñado con estética clásica premium, optimizado para alto rendimiento (100/100 Lighthouse), accesibilidad completa (WCAG) y visualización en dispositivos móviles y de escritorio.

## 🚀 Despliegue en GitHub Pages y Vercel

### Despliegue en Vercel
1. Conecta este repositorio en tu cuenta de [Vercel](https://vercel.com).
2. El archivo `vercel.json` preconfigura el framework Astro automáticamente.
3. Build command: `npm run build` | Output directory: `dist`.

### Despliegue en GitHub Pages
1. Workflow automatizado de GitHub Actions en `.github/workflows/deploy.yml`.
2. En GitHub, en **Settings > Pages**, selecciona **GitHub Actions** como Source.
